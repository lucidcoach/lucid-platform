이용약관

시행일: 2026년 10월 2일

본 약관은 Lucid 홈페이지, Discord 봇, 커뮤니티·전적·스트리밍 페이지 및 코칭 연결 서비스에 적용됩니다.

1. 서비스 내용

Lucid는 League of Legends 내전 운영, 경기 기록·경기 후 분석, 스트리머 전적 페이지, 커뮤니티 기능과 코칭 상품 탐색·예약 기능을 제공합니다. AI Score, MVP·ACE, 분석 리포트는 Lucid가 생성한 참고용 파생 결과이며 Riot Games의 공식 등급이나 평가가 아닙니다.

2. 계정과 외부 서비스 연결

사이트 계정은 이메일 또는 지원되는 OAuth 방식으로 생성할 수 있습니다. Discord 연결은 Discord 봇에서 등록한 Riot ID와 사이트 계정을 연결하기 위한 기능입니다. Discord 로그인이나 서버 가입만으로 커스텀 경기 공개에 동의한 것으로 처리하지 않습니다.

3. 등록된 Riot ID

Lucid에 표시되는 Riot ID는 사용자가 등록한 계정 정보입니다. 공식 API 조회가 완료된 ID는 PUUID와 연결되며, 기존 수동 등록 기록에는 조회 전 정보가 남아 있을 수 있습니다. 현재 Riot Sign On(RSO)을 통한 계정 소유권 인증은 제공하지 않으며 화면에는 ‘등록된 Riot ID’로 표시합니다. RSO는 Production 승인 이후 별도 구현·검증이 필요한 기능입니다.

4. 커스텀 경기 공개

커스텀 내전 기록 공개는 기본 OFF입니다. 경기 참가자 전원이 해당 공개 범위에 명시적으로 동의한 경기만 공개합니다. 사용자는 언제든 동의를 철회할 수 있고, 철회하면 기존 공개 페이지에서도 해당 기록이 제외됩니다. 내부 운영 기록 보관과 공개 여부는 서로 분리됩니다.

5. 코칭·결제

코칭 상품의 내용, 가격, 일정과 제공자는 각 상품 화면에 표시합니다. 현재 홈페이지 결제는 테스트 모드이며 실제 금액이 청구되지 않습니다. 실제 결제가 활성화된 경우 결제 화면과 결제·환불 안내에 표시된 조건이 적용됩니다.

6. 이용자의 의무

  • 타인의 계정·개인정보 또는 경기 데이터를 무단으로 등록하거나 이용하지 않습니다.
  • 서비스 방해, 취약점 악용, 허위 정보 입력, 불법 행위를 하지 않습니다.
  • Discord, Riot Games, CHZZK 및 결제 제공자의 약관을 준수합니다.

7. 서비스 제한과 변경

보안, 장애, 외부 API 변경 또는 정책 준수를 위해 일부 기능을 일시 제한할 수 있습니다. 중요한 변경은 홈페이지 또는 서비스 내 공지로 안내합니다.

8. 계정 해지와 데이터

로그인 사용자는 설정에서 Lucid 계정을 삭제할 수 있습니다. 계정 삭제 시 로그인 정보와 외부 로그인 연결은 제거되고 계정은 비활성화됩니다. 결제·정산·예약·분쟁 대응 기록 및 Discord 서버의 내부 경기 기록은 별도 기록이므로 즉시 함께 삭제되지 않을 수 있습니다. Riot ID 등록 해제, 공개 동의 철회, 개인정보 삭제 요청은 설정의 각 기능에서 별도로 처리할 수 있습니다.

9. 책임 범위

외부 플랫폼 장애, 통신 장애 또는 사용자의 귀책으로 발생한 손해에 대해서는 관련 법령이 허용하는 범위에서 책임이 제한됩니다. Lucid 분석 결과는 코칭과 경기 복기를 돕는 참고 정보입니다.

10. 문의

서비스, 계정, 데이터 및 정책 문의는 문의·지원 페이지에서 접수할 수 있습니다.
