Riot 데이터 이용 안내

Lucid가 League of Legends 데이터를 사용하는 방식

Lucid는 Riot Games의 공식 서비스가 아닙니다. 공식 Riot API 데이터와 사용자가 제공한 ROFL을 경기 후 분석에 사용하며, 공개 커스텀 경기 기록은 명시적인 opt-in으로만 제공합니다.

1. 서비스 목적

Lucid는 내전 운영, 경기 기록, KDA·CS·피해량·아이템 등 상세 통계, 경기 후 분석과 코칭 참고 자료를 제공합니다. 공식 랭크를 대체하는 MMR·ELO 서비스는 제공하지 않으며 내부 팀 밸런싱 값은 공개하지 않습니다.

2. 공식 Riot API 데이터

등록된 Riot ID를 ACCOUNT-V1로 조회해 PUUID를 확인하고, MATCH-V5 등 지원되는 API의 경기 데이터를 수집합니다. Riot ID는 사용자 화면에 표시될 수 있지만 PUUID는 백엔드 식별자로만 사용합니다.

3. ROFL 데이터

관리자 또는 사용자가 업로드한 ROFL에서 경기 상세 통계를 추출합니다. raw ROFL 원본은 14일 후 자동 삭제하고, 추출된 구조화 통계는 경기 분석 기록과 분리해 보관합니다.

4. Lucid 파생 데이터

AI Score, MVP·ACE와 분석 리포트는 공식 Riot 평가가 아니라 Lucid가 경기 후 데이터를 바탕으로 생성한 참고 정보입니다.

5. 커스텀 경기 공개 동의

  • 기본값은 OFF
    사용자가 직접 켜기 전에는 공개 동의가 없습니다.
  • 로그인·서버 가입과 별개
    Discord 로그인, Discord 서버 가입, Riot ID 등록은 공개 동의가 아닙니다.
  • 전원 동의
    해당 경기 참가자 전원이 같은 공개 범위에 동의한 경우에만 경기 상세를 공개합니다.
  • 언제든 철회
    철회 즉시 과거·신규 공개 페이지에서 해당 사용자가 포함된 커스텀 경기 기록이 제외됩니다.
  • 내부 기록과 공개는 별개
    내전 운영, 분쟁 대응 및 기록 무결성을 위한 내부 데이터는 공개 철회만으로 삭제되지 않습니다.

6. 공개될 수 있는 데이터

Riot ID, 경기 참가 여부, 승패, 챔피언, KDA, CS, 피해량, 아이템, 경기 통계, AI Score, MVP·ACE 및 경기 후 분석이 포함될 수 있습니다. PUUID와 내부 팀 밸런싱 값은 공개하지 않습니다.

7. 등록된 Riot ID와 RSO

현재 Riot ID는 Lucid에 등록된 정보이며 Riot Sign On 기반 소유권 인증은 제공하지 않습니다. Production 승인 이후 RSO 기능을 도입하더라도 기존 ‘등록’ 상태와 별도로 표시합니다.

8. 연결 해제와 삭제

로그인 후 내 정보에서 Riot ID 등록 해제, 공개 동의 철회, 계정 삭제 및 개인정보 삭제 요청을 할 수 있습니다. raw ROFL 보관·삭제 상태도 같은 화면에서 확인할 수 있습니다.

9. 무료·유료 구분

커뮤니티 내전 운영, 공개 동의 관리와 공개된 경기 기록 열람은 무료 기능입니다. 코칭은 코치의 시간과 피드백 서비스에 대한 별도 상품이며, 현재 사이트 결제는 테스트 모드입니다. Riot API 원본 데이터 자체를 판매하지 않습니다.
