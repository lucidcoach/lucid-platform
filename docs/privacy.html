2. 커스텀 경기 공개

공개 동의는 기본 OFF이며 Discord 로그인이나 서버 가입과 별개입니다. 참가자 전원의 유효한 동의가 있어야 경기 상세가 공개됩니다. 철회하면 과거 및 신규 공개 응답에서 즉시 제외되며, 내부 운영 기록 자체를 자동 삭제하지는 않습니다. 자세한 범위는 Riot 데이터 이용 안내에서 확인할 수 있습니다.

3. 외부 서비스와 처리 기반

Lucid는 기능 제공을 위해 Discord, Riot Games API, CHZZK, Google·Naver OAuth, Toss Payments 및 호스팅·데이터베이스 제공자를 이용할 수 있습니다. 각 제공자는 해당 요청 처리에 필요한 범위에서 정보를 처리합니다.

4. 삭제·정정·연결 해제

로그인 사용자는 설정에서 Riot ID 등록 해제, 커스텀 경기 공개 동의 철회, Lucid 계정 삭제 및 개인정보 삭제 요청을 할 수 있습니다. 계정 삭제는 사이트 로그인 계정을 비활성화하고 로그인 연결·Riot ID 사본·정산 계좌를 제거하지만, Discord 서버 기록과 거래·예약 기록은 별도 처리됩니다.

5. 보호조치

HTTPS, 접근 권한 분리, 비밀키의 환경변수 관리, 공개 응답 직렬화와 동의 게이트를 적용합니다. Riot API key, PUUID, 내부 팀 밸런싱 값은 브라우저 공개 응답에 포함하지 않습니다.

6. 문의

열람·정정·삭제 및 개인정보 문의는 문의·지원 페이지 또는 로그인 후 설정의 ‘개인정보 삭제 요청’에서 접수할 수 있습니다.
